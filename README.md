# 🖥️ MiniConsola JS — Práctica de JavaScript

MiniConsola JS es una herramienta educativa interactiva para practicar JavaScript directamente desde el navegador. Con una interfaz inspirada en Visual Studio Code, permite escribir código en un editor y ver el resultado en una consola que simula la salida de Node.js.

Está diseñada para el módulo de **Desarrollo Web en Entorno Cliente (DWEC)** del ciclo formativo de **Desarrollo de Aplicaciones Web (DAW)**.

## ✨ Características

- **Editor de código** con sangrado automático (Tab = 2 espacios).
- **Consola simulada** que imita el formato de salida de Node.js (`console.log`, `console.error`, `console.warn`, `console.table`, etc.).
- **Formateo inteligente de valores**: objetos, arrays, Mapas, Sets, fechas, expresiones regulares, funciones y referencias circulares.
- **Ejemplos integrados** listos para ejecutar: Hola mundo, variables y tipos, operaciones aritméticas, estructuras de control, arrays, objetos, funciones y manejo de errores.
- **Sin dependencias externas**: un único archivo HTML, sin librerías ni conexión a Internet.
- **Interfaz oscura** estilo VS Code, responsive y adaptable a móviles.

## 🚀 Uso

1. Descarga el archivo `mini-consola-js.html`.
2. Ábrelo en cualquier navegador moderno (Chrome, Firefox, Edge, Safari).
3. Escribe código JavaScript en el panel izquierdo.
4. Pulsa **Ctrl+Enter** o el botón **▶ Ejecutar**.
5. El resultado aparecerá en la consola de la derecha.

## ⌨️ Atajos de teclado

| Atajo | Acción |
|-------|--------|
| `Ctrl + Enter` | Ejecutar el código |
| `Tab` | Insertar dos espacios (sangrado) |

## 📚 Ejemplos incluidos

Pulsa el botón **Ejemplos** para cargar código de muestra sobre:

1. Hola mundo
2. Variables y tipos
3. Operaciones aritméticas
4. Estructuras de control (condicionales y bucles)
5. Arrays
6. Objetos
7. Funciones (incluyendo recursividad)
8. Manejo de errores (try/catch)

## 🎯 Objetivos didácticos

Esta herramienta está pensada para que los alumnos:

- Practiquen la sintaxis básica de JavaScript sin necesidad de instalar nada.
- Comprendan los tipos de datos y su representación en consola.
- Experimenten con estructuras de control, arrays, objetos y funciones.
- Aprendan a depurar errores mediante mensajes de consola.
- Se familiaricen con un entorno de desarrollo similar al profesional.

## 🔧 Tecnologías

- HTML5
- CSS3 (variables CSS, Flexbox, media queries)
- JavaScript (ES6+, API DOM, `new Function` para ejecución en sandbox)
